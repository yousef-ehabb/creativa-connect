# Creativa Hub Aswan — Unified Digital Portal

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fyousef-ehabb%2Fcreativa-connect)

Official central entry point for Creativa Hub Aswan students and staff. Direct access to assessments, attendance, and transportation services from one single link.

---

## 🚀 Integrated Portals

| Portal | Role | Direct Target URL |
|---|---|---|
| **Assessments** | Pre & Post Training Assessments | [creativa-assessment-portal.vercel.app](https://creativa-assessment-portal.vercel.app/) |
| **Attendance** | Daily Check-in & Certificate Tracking | [creativa-attendance.vercel.app](https://creativa-attendance.vercel.app/) |
| **Rakeb** | Student Transportation & Bus Registration | [rakeb.vercel.app](https://rakeb.vercel.app/) |

---

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS (Custom Creativa Design System Tokens)
- **Icons:** Lucide React
- **Animations:** Framer Motion

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
